## 测试发现和修复

真实修复场景通过后，测试脚本的额外恢复步骤产生了 NAT/DHCP 不一致配置；工作程序拒绝修复且未改网卡。最初的备份恢复又漏检注册表中的 /23 掩码残留，造成编辑器提示 VMnet1 子网与掩码不匹配。原始失败记录保留，未改成通过。随后通过原编辑器将 VMnet1 恢复为正确的 /24，并新增注册表掩码与 DHCP 一致性校验、掩码变更检测及相应回归测试。最终恢复验收同时核对注册表、DHCP 和实际网卡，避免只检查 IP 就宣布恢复。

新增网络首先由用户在原编辑器手动创建并应用，自动同步和退出由实际已安装任务完成；其后的跨子网和开关测试使用同一原编辑器，修正测试驱动后完整重跑。自定义网络的验收报告保留当时运行代码的哈希；最终安装代码另与发行源文件逐项核对一致。

## 复验方法和范围

自动测试命令见 README。`Test-Integration.ps1` 是可独立运行的管理员隔离事件测试，它禁止实际续租/重启服务，不应当作真实修复证明。上述实网测试另行通过 VMware 原编辑器和实际已安装任务完成。

复验旧租约问题时，在备用测试机备份配置，保证无虚拟机运行；分别保存编辑器产生的新旧配置及 DHCP 服务绑定等相关注册表状态；保留旧 DHCP 租约，完整重放新配置并确认服务运行。不要只替换子网文件而保留旧服务绑定。先确认实际网卡确实仍为旧地址且 DHCP 已启用，再等待真实事件任务。验收要求有真实定向续租记录、最终地址/前缀/路由正确、连续复核成功、未修改另一网卡及工作程序退出；单独的 ipconfig 返回码 0 不算通过。完成后恢复备份，并针对目标网卡释放旧租约后重新申请以验证恢复成功。

其他 Windows/Workstation 版本、企业组策略环境及自定义 NAT 位置的实网兼容性尚未逐一测试。自定义 NAT 的解析、任意网关/宿主机地址和非 /24 前缀已通过自动测试。`Synced` 验证宿主机网络一致性，不代表客体 SSH/DNS 或全部 NAT 转发规则可达。
